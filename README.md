# Sales Data ETL Validation Project

## Project Overview
This project demonstrates ETL (Extract, Transform, Load) testing using MySQL. The objective of this project is to validate the accuracy and consistency of data transferred from source systems to target databases.

## Technologies Used
- MySQL
- SQL
- ETL Testing
- Microsoft Excel
- GitHub

## ETL Workflow
Source CSV File
↓
Source Table
↓
Transformation Logic
↓
Target Table
↓
Validation Testing

## Validations Performed
- Row Count Validation
- Null Validation
- Duplicate Validation
- Source-to-Target Validation
- Transformation Validation
